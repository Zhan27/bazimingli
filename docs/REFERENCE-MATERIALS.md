采用的是功能思路，由本项目独立实现：

- 在原有JSON计算契约之外增加学习事实视图：每柱藏干十神、支本气十神、纳音、十二长生、按日柱旬判断的空亡。

- 每步大运包含10个流年，并提供12个流月的精确节界。数据均来自现有本地计算。
- 通过已保存的JSON离线比较已提供字段，明确遗漏项、异名和口径差异；不自动调用或依赖第三方接口。

## 对照方法

网页中完成综合排盘后，点击工具栏“细读与核验”。“四柱细读”展示基础表项；“大运流年”可选运步、年份并查看节气流月；“离线对照”可导入已有JSON，默认只看差异和未提供项，也可展开一致字段。底部“导出本盘数据”生成版本化学习快照；导出对照报告只包含支持的比较字段与提示。文件不写入记录，含出生信息的导出文件请自行保管。

```powershell
node scripts/compare-reference.cjs --input birth-input.json --reference saved-reference.json --out new-report.json
# 已有本项目计算JSON或学习快照时：
node scripts/compare-reference.cjs --local own-snapshot.json --reference saved-reference.json --out new-report.json
```

输入文件最多2MB，输出文件必须不存在。`birth-input.json`使用[API输入格式](API.md)，请明确填写时区、夏令时、换日和真太阳时选项。工具完全离线，不执行输入内容，也不保存API设置。

支持本项目JSON/学习快照、四柱字符串数组，以及`{action:"chart",data:{input,pillars:{year,month,day,hour},dayun}}`式已保存响应。不是任意网站数据的自动识别器；未知结构或无效干支会报错。农历形式的外部出生年月日不会当作公历日期比较。

每项状态为`same`、`different`或`not-provided`。藏干比较集合，不把排列差异当作成员缺失；泉中水/井泉水、城头土/城墙土、砂中金/沙中金、砂中土/沙中土、佛灯火/覆灯火使用显式异名映射，保留双方原文和`normalizedAlias`标记。大运只比较共有步数，并提示覆盖范围；起运年龄另列口径提示，不据此判定一方错误。

未知时区、DST、换日或真太阳时选项会保留提示。`aligned-with-gaps`表示已有字段一致但核验不完整；`aligned`只表示支持字段及声明口径一致，不是准确性认证。强弱分制、用神、格局、神煞集合、AI文字和藏干次气权重不纳入一致率。

## 样本结论与保留事项

提供的1990-05-20 10:30男性样本，按本库UTC+8、不使用夏令时/真太阳时、子初换日设置，得到38项一致、0项数值差异、1项未提供；第三方日柱干十神未提供，双方时区等4项口径未同时声明。本库8步大运、样本9步，仅比较共有8步的干支序列。起运年龄虽同为6，首步起始公历年本库1996、样本1995，8步均有1年的偏移，另列年龄/交运口径提示，不计入字段一致数。精确交运日期和流年年龄未纳入一致率。该结论只针对这一个保存样本，不能外推到全部日期或预测效果。

巳支的次气顺序在两边不同。本库保留原藏干数组及评分权重，仅标识本气，不根据数组次序新增中气/余气分类。古籍原文、连续强弱分值、服务鉴权/限流、数据库与收费模式未从抓取物直接移植；后续如需这些功能，应按各自来源和实际部署条件另行核验。

流年年龄沿用现有时间轴的“公历年减有效出生公历年”口径；年度干支指该年立春后的年柱。流月属于立春至下一立春的12个节月，节界为北京时间，使用左闭右开区间，不能等同于整公历月或农历月。空亡标志统一参照原局日柱的旬。旧计算JSON、规则版本和AI命盘标识不因新增学习视图而改变。
