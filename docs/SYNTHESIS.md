# 命格总断与资料吸收

## 本轮机制

总断、子平格局细盘、综合参考、结尾总论和 PNG 提纲共用 `buildMingGeSummary`。它读取已有四柱、五态旺衰及当前流派取用，不修改历法、旺衰权重、用神选择、AI Prompt 模板、记录格式或 JSON 身份。

1. **月令起点**：显示月支本气及其十神、所有月支藏干的透藏情况。显示“正官提纲”等，不把旧评分的“中上格局”当作格名。比劫月令另看财官食伤配合；本气提纲不冒充杂气/会局取格的完整算法。
2. **按提纲分路**：官看财印承接及伤官、官杀；财看食伤生财、官星护财与比劫；印看官杀生印与财印；食伤看生财、制杀、配印；杀看制化。每项保留具体干支和柱位，日干作为坐标，不当作额外比肩助力。
3. **救应分层**：列出透干有根、透干待根、藏干待引、原局未见；根指四支藏干有同五行。若对应克制者也明透，则标“救应受牵”。并见不直接判已化解，食伤出现不直接判官杀已清。状态用“配合有根 / 救应线索 / 制化待察”等描述筛选结果。
4. **原局与行运分开**：大运只列运干、运支藏干中出现的取用或救应字及年龄段，不反向改写原局状态，不把含有一字换成必吉的运势分数。
5. **紧凑展示**：默认保留一句总论、承接、关节、取用。柱位、行运、原文链接按需展开；旧评分、财富/学历档位演示仍在综合参考的旧规则折叠中。修复旧账本月令食伤项误列 -6 和标签错配，分数本身不变。

这是明透组合与藏干根气的确定性筛选层，尚不计算精确制化强度、合去取清或完整外格。原有“从弱”标签进入从势复核路线，不能据此自动认证真从格。多流派取用与调候分列；软件权重和古文语境分别说明。
