## 喜忌顺序

1. 先读五态旺衰与得令、通根、得势。身强/身极强以财官食伤为扶抑喜向，印比再增需察；身弱先印比，财官食伤结合承受。中和沿月令承接路线列出当前喜向，其余五行留待制化细分；从弱显示顺势观察并结合根气。
2. 展示当前流派选择、扶抑取用与寒暖调候。调候恰落在扶抑耗泄方向时，直接列出两种作用。
3. 喜向和增势方向是分组，不再硬凑用/喜/忌/仇/闲五个互异五行。生用或克用本身不决定喜忌。
4. 流年干支分别判断，两向相反显示喜忌交杂。大运曲线为基准50，干支喜向各+18、增势各−18，中和仅所选承接五行+18，其余0；日支六冲−6（差值严格为6，重复地支不当六冲），限制6–94。它与原局结构分分开。
