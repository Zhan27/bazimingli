# 旺衰、喜忌与结构评分1.0.0

5.29 将展示层喜忌与命局结构评分统一。四柱、月令旺衰得分、五个流派的原有取用结果、AI契约与历史结构均保留；新模型只读命盘，不写回排盘事实。

## 喜忌顺序

1. 先读五态旺衰与得令、通根、得势。身强/身极强以财官食伤为扶抑喜向，印比再增需察；身弱先印比，财官食伤结合承受。中和不硬分五行喜忌，从弱显示顺势观察并结合根气。
2. 展示当前流派选择、扶抑取用与寒暖调候。调候恰落在扶抑耗泄方向时，直接列出两种作用。
3. 喜向和增势方向是分组，不再硬凑用/喜/忌/仇/闲五个互异五行。生用或克用本身不决定喜忌。
4. 流年干支分别判断，两向相反显示喜忌交杂。大运曲线为基准50，干支喜向各+18、增势各−18，中和各0；日支六冲−6（差值严格为6，重复地支不当六冲），限制6–94。它与原局结构分分开。

## 评分明细

|分项|满分|规则|
|---|---:|---|
|扶抑配合|30|按当前旺衰方向，天干和支本气各计一位，所需五行每位10分，3位封顶；中和取20，继续由提纲与制化分项细分。|
|喜用透根|25|只查扶抑所需五行，中和查当前扶抑取用；明透有根25，明透无根15，仅藏支10，未见0。日干不作为额外助力。|
|提纲承接|25|复用总断的月令候选路径，按必要出现、明透、有根检查的满足比例计分，取承接最完整的一条；力量复核项不计为已满足。|
|关节制化|10|按总断中明透阻力对应救应：有根10、有根但受牵8、明透待根6、藏干待引3、未见0；同一关节取承接最完整的救应路线，多个关节取平均，无所筛阻力取10。|
|寒暖配合|10|无冬夏专项10；调候字明透有根10，明透无根6，仅藏4，未见0；扶抑冲突另列。|

分项各自四舍五入，合计即总分（0–100）。80/60/40分分别显示配合较全/已有承接/局部承接，其余着重补配；名称不替代月令提纲。没有未来大运加分、关系条数扣分、保底分或按分数换算财富金额/学历等级。权重是应用的显式规则设计，并非古籍给出的数字或用真实人生结果拟合的模型。
