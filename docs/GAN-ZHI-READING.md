# 干支交互与释义出处

综合盘显示关系摘要，点击打开八字交互面板。年、月、日、时分四列，天干在上、地支在下。类型筛选、点字定位和关系选择均使用现有柱位模型；三合、三刑、自刑连接全部参与柱位。箭头默认浅色，选中后加深，端点距字框约5px，柱位标签位于框内。

关系判定继续由 [relations.js](../src/bazi/relations.js) 提供，展示由 [gan-zhi-workspace.js](../src/ui/gan-zhi-workspace.js) 处理。[relation-notes.js](../src/ui/relation-notes.js) 的释义与引文不进入计算、AI Prompt、记录或序列化命盘。

## 阅读方式

“关系含义”说明五行牵制、联结与成局条件；“盘内看点”根据当前日干列出参与柱位的十神，地支采用本气十神。“传统取象”为本页整理的学习解释；古籍短引单独置于可展开的出处区，点击书名可查看原文。

例如甲庚冲按金木制约解释；甲日主遇寅午半合时，连接木生火、食伤、制杀与生财的阅读路线。没有午的寅戌半合不会写成寅午联动。半合继续显示缺支和成局条件，保持原有关系名称。
