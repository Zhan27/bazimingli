# 记录与备份

页面底部「统一记录管理」集中管理已有五类记录：综合八字、八字页、紫微斗数、奇门遁甲、六爻。合婚目前没有独立持久记录库，不计入这五类。

可以按模块筛选，用姓名、日期、地点、备注或排盘文字搜索，按更新顺序、出生日期或姓名排序。每条记录可写最多1000字符备注，并重新排盘。备注保留在原记录中，重新排盘不会清掉它；备注也会随备份导出，可能包含个人信息。

「选择当前结果」只改变当前筛选结果的选中状态。切换筛选后选中项仍保留，状态条会显示跨筛选选中数量；删除时再次提示实际数量。模块键与记录ID一起标识记录，不会因为不同模块ID相同而误删。

## 两种备份语义

| 格式 | 内容 | 当前版本导入行为 |
|---|---|---|
| v4/v5完整备份 | 原有完整导出，保留兼容性 | 替换文件包含的对应类记录，未包含的类不变 |
| v6-selection选中备份 | 只含主动选中的类与记录 | 与对应类合并，同ID使用文件中的版本，未选中记录保留 |

选中备份使用独立版本，5.20及更早版本会明确拒绝，不会把部分备份误当成完整备份覆盖原数据。每类合并后仍最多50条，超出时在写入前拒绝，请先整理或分批。导入文件和下载备份限制2MB；大批备注可以用选中导出分批保存。

所有导出只包含已知记录字段，不包含API配置、Key或AI会话草稿。备注是自由文本，请勿主动写入凭据。完整备份和选中备份都可能包含出生信息，文件由用户自行保管。

删除或清空只处理五类记录及已迁移的旧版主记录键；API设置、AI草稿、当前表单、剪贴板和已导出的文件各自独立。清空不是对硬盘残留或第三方留存的安全擦除承诺。多类写入失败会尝试回滚并明确报告失败；若浏览器同时拒绝回滚，请保留原备份并先解决存储问题。

单卡AI导出是独立JSON：包含该维的解释、引用的事实值、来源状态和生成元数据，明确结构校验或未校验状态；不附加完整出生输入或API设置。单卡内容同样由用户决定如何分享。

5.21仅修改界面和记录管理，计算规则版本保留5.20.0，避免仅更新界面就让兼容的AI草稿失去命盘身份匹配。以后规则或数据真实变化时才增加规则版本；应用发布版本独立更新。
