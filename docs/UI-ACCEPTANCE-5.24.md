# v5.24.0 界面验收

日期：2026-10-23。采用用户确认的紧凑综合盘与八字交互概念，继续使用单HTML交付，没有新增依赖或框架。

## 改动范围

- `src/ui/compact-workbench.js`：四柱紧凑表、五行及大运速览、完整旧内容折叠、操作收纳、手机编辑/记录/AI入口与成功排盘后收起；大运按钮定位并高亮原表格对应行。
- `src/ui/gan-zhi-workspace.js`：独立交互面板，八字固定柱位、分层浅色箭头、类型筛选、点字定位、关系选择、重置、键盘关闭和焦点恢复；替换原逐行关系轨道。
- `src/ui/relation-notes.js`：随当前日干生成十神看点，显示传统释义与折叠出处；引文与整理文字分开，配对仍由原关系模型提供。
- `src/ui/workbench.js`、`workbench.css`、`scripts/source-list.cjs`：展示接入、窄导航、三主题、弹窗可视高度与滚动，保留既有输入ID和事件。
- 原卡片、藏干权重、司令、五行流通图、喜用神、所有术数、AI Prompt、草稿、历史、导入导出及配置功能均保留。历法、排盘引擎、AI/存储/JSON契约和规则版本5.20.0未修改。

`npm run verify`完整成功：69项Node测试、5项Python桌面测试、46项Chrome端到端测试，共120项，无跳过、失败或重试通过。静态检查0错误、37项既有警告、0新增警告。

覆盖六个模块排盘，公历/农历互转与闰月，具体时分/时区/DST/换日，未知时辰，五流派与五行口径，命盘身份和既有回归；记录搜索、重排、备注、导出/清除/导入与回滚；模拟AI生成/取消/失败/恢复/18维输出，Prompt、PNG与JSON导出；学习、运年流月、离线核验、设置与各类弹窗。未请求实际付费模型。

新增关系检查包括13组密集关系、同字四柱、自刑/三刑/三合全部端点、空关系、类型筛选、键盘选择、关闭返回焦点、释义出处及安全文本。新增紧凑盘检查包括完整旧内容可达、手机编辑成功/错误、实际备份下载、选定大运定位、当前命盘与记录未被阅读操作改写。
