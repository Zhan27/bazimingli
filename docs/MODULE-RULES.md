# 模块规则与交互核验（5.27）

本次保留现有单HTML及AI模板，按模块拆分计算事实和界面展示。六爻、合婚、奇门规则标记为5.27.0；四柱、旺衰与取用仍使用原5.20.0，八字页和综合页共用总断、条件检查及柱位证据。

## 六爻

- 摇卦采用三枚独立公平铜钱，背面数0/1/2/3概率为1/8、3/8、3/8、1/8。手动六爻序列依次为初至上；所有动爻一起翻转。
- 时间起卦按年支数子1至亥12、农历月日、时支数；上卦为年月日之和，下卦再加时，六取余定位动爻。乾1至坤8，余0作8。闰月仍用同月数，作为本应用明示约定。
- 月建使用实际交节时刻，日辰/旬空使用选定换日，六神自初爻向上。无日期的数字/铜钱输入不凭空指定甲日六神。本变六亲均以本卦宫五行为基准。
- 点爻位打开本变纳甲、六亲、世应、月破与旬空。旧取数入口保留；没有版本的旧记录重排自动选旧版，新旧输入分别记录。

取数及两个数值例：[《梅花易数》卷一](https://zh.wikisource.org/wiki/梅花易數/卷一)；六神起序：[《卜筮全书》起六神诀](https://www.shidianguji.com/zh/book/HY1394/chapter/1l3wdoooukqb8)。原文规则与概率/遍历测试分别列于[测试来源](../tests/fixtures/SOURCES.md)。

## 奇门

符头以最近甲/己日定位，子午卯酉为上元、寅申巳亥为中元、辰戌丑未为下元。旬首先取六甲遁仪，再在地盘寻宫；值符随时干，值使从旬首原宫按旬内时序阳顺阴逆计九宫，二者落宫各自计算。

本应用采用转盘八宫顺序坎艮震巽离坤兑乾，禽随芮，落中五寄坤二。天盘干随其原星转动，中宫干作为寄干同行；地盘、九星、八门、八神及标记均由引擎生成，页面只读取同一结果，点宫展开依据。独立表单按东八区输入；API可明示子初/子正换日，交节仍按实际时刻。

符头、局数表、符使：[《易学象数论·遁甲》](https://www.eee-learning.com/book/1345)；盘例：[《遁甲演义》卷二](https://zh.wikisource.org/wiki/遁甲演義_(四庫全書本)/卷2)。八宫转盘及寄宫规则为本应用明确采用的约定，并不涵盖所有古籍与流派的寄宫变化。**旧选项“置闰”已改称“旧版日干支分段（近似）”；真正超神、接气、闰奇全流程尚未实现。**

## 合婚

修复六合双向、子未/丑午等六害表与桃花查表；用神受克按双方各自计算。所有大运同步及流年窗口共用表单指定的参考年份，交换双方不改变指数。

先显示双盘、指数与亮点；各维度和原有深度研判可分别展开。指数为基础60加各调整，展示限制在30至95；台账公开原总数。深度研判原有提示数不再伪装成额外计分。双盘交互按甲乙具体年/月/日/时定位，可切干支、筛柱位和选择关系。

基础关系表：[《三命通会》卷二](https://zh.wikisource.org/wiki/三命通會/卷二)。权重、命卦/星曜配对等仍为应用参考规则，不因查表修正变为经现实数据校准的模型。双方具体时分、时区/夏令时、流派、真太阳时及统计口径可保存、交换和从记录恢复；版本兼容详见[记录与备份](RECORDS.md)。

## 导出与兼容

“导出命盘图”保持原默认内容；“选择图片内容”可分别控制姓名/性别/日期、十神、提纲旺衰、旧演示分、大运和五行。取消个人信息时下载文件名也不带姓名日期。文字按实际画布宽度换行。

没有迁移框架、改变API配置或删除历史功能。算法修正后的新结果可能与旧版不同，旧模块规则版本用于追溯；旧全部算法并未整套模拟。测试覆盖规则、备份、真实浏览器交互和布局，不代表术数预测效度或原生WebView所有机型都已测试。
